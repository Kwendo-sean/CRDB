# Production deployment

The production target is a self-contained Ubuntu VPS. The stack does not require Vercel, Firebase, Supabase, Railway, Render, or managed database services.

## Topology

```text
Internet -> Nginx :80/:443 -> web (Gunicorn + Uvicorn ASGI)
                                  |-> PostgreSQL
                                  |-> Redis (Channels + Celery)
                       Celery worker / Celery Beat
```

HTTP and WebSockets share one ASGI service to keep operation simple. PostgreSQL, Redis, application static assets, and media use Docker volumes. Only Nginx publishes host ports.

## Fresh server

1. Use a current Ubuntu LTS VPS with a non-root sudo user and DNS already pointing to the server.
2. Clone the repository.
3. Copy `.env.example` to `.env` and set `DOMAIN`, `SSL_EMAIL`, the official Form URL, PAL values, hosts, and origins. Empty secrets are generated by the setup script.
4. Run `sudo bash server_setup.sh`.
5. Create the first operator: `docker compose exec web python manage.py createsuperuser`.
6. Open `https://DOMAIN/control/`.

The setup script installs Docker, configures UFW, builds containers, derives `DJANGO_ALLOWED_HOSTS`/`CSRF_TRUSTED_ORIGINS`/`APP_BASE_URL` from `DOMAIN`, runs a configuration preflight, starts data services, runs migrations/static collection/role setup, optionally provisions Let's Encrypt, installs the backup cron job, and verifies `/health/`.

`manage.py check` refuses to start a production deployment that would fail under
load: missing Redis (`core.E001`), SQLite in production (`core.E002`),
local-only allowed hosts (`core.E003`) or HTTPS without trusted CSRF origins
(`core.E004`). See `GO_LIVE.md` for the full run order.

## Updates

Run `sudo ./deploy.sh`. It requires a clean, fast-forwardable checkout, rebuilds images, applies migrations, recollects static assets, restarts services, and verifies health.

## Operations

```bash
docker compose ps
docker compose logs -f web
docker compose logs -f celery
docker compose exec web python manage.py check
docker compose exec web python manage.py createsuperuser
```
